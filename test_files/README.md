# A11y Checker Test Fixture

Keep the notebook and three PNG files in the same folder.

Key questions:
1. Does missing alt text get flagged while poor-but-present alt text passes?
2. Does the same image get different AI alt text under different notebook context?
3. Which link-text examples are flagged?
4. Are AI suggestions limited to image alt text and table captions?
5. Does table-caption AI use surrounding notebook context?
6. Does image contrast detection run, and does styled HTML text contrast get detected?
7. Does the checker detect heading hierarchy problems?
8. Does it analyze accessibility issues produced by code-cell output?
